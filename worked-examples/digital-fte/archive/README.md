# archive/

Throwaway scratch scripts kept for reference, not part of the build. These are
ad-hoc `asyncpg` queries that sub-agents wrote while inspecting the `tickets`
table during skill trigger-evaluation runs. They have hardcoded paths and are
not maintained. Safe to delete.

Originally they sat in the project root with names like `_q.py` / `_queue.py`,
where root-level `_*.py` files risk shadowing stdlib imports — moved here to keep
the project root clean.
